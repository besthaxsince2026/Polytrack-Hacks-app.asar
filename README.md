# Polytrack-Hacks-app.asar
This is a hack for polytrack to slow your game down for cracked times
**how to use them?**
**1** go to kodub.itch.io and select polytrack
**2** scroll down and click download 
**3** click on continue to download
**4** download it 
**5** unzip the file and click on resources in the polytrack map
**6** download my app.asar and replace it with the existing one 
**7** go back and start Polytrack.exe
**keybinds**
F1 plays the game at 25%
F2 plays the game at 50%
F3 plays the game at 75%
F4 plays the game at 100% (original)
